# Architecture decision records

One file per decision: `0001-<slug>.md`. A bet from `docs/stack.md` becomes an ADR when it is confirmed by play or replaced.

Pending: `0001-kernel-primitives.md` (ROADMAP Phase 0).

## Template

```markdown
# ADR-NNNN: <title>

Date:
Status: proposed | accepted | superseded by ADR-NNNN

## Context
What forced the decision. Link the playtest or spike if one did.

## Decision
One paragraph. What we do.

## Consequences
What gets easier, what gets harder, what we watch for.

## Alternatives considered
Short list with the reason each lost.
```
