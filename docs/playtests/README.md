# Playtests

One file per slice: `slice-01.md`, `slice-02.md`, … A slice is not done until its file exists.

## Template

```markdown
# Slice N - <name>

Date:
Build: <commit>
Campaign: <name of the fixture campaign>
Model: <if AI was involved>

## What I played
Two or three sentences. What kind of session, how long.

## What broke
Bugs. Each one becomes a test or an issue.

## What felt wrong
Not bugs. Friction, missing affordances, things Obsidian/Fibery/LegendKeeper/Risu do better.

## What changed as a result
Decisions, roadmap edits, bets revised.
```
